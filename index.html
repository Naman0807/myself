001

Production

Patient AI Assistant

Problem
An in-app assistant had to answer from one patient's own records, refuse medical advice, and never reach another patient's data.
Built
A tool-calling agent on Azure OpenAI (GPT-6 Luna): 7 typed tools, a turn-capped loop with memory, guardrails before and after the model, identity taken from the server session.
Result
23/23 behavior evals pass on the live model, backed by 80 unit tests and 100% branch coverage. CI runs a deterministic stub with no network calls.
Client work · details on request
ModelThe language model behind the assistant: GPT-6 Luna, served through Azure OpenAI.
GPT-6 Luna · Azure
ToolsTyped functions the model is allowed to call, each with a fixed input schema. Seven of them read the patient's own records, such as visits, medications, consent status, rewards and saved studies.
7 typed functions
Eval23 curated prompts sent to the live model. Each one checks in-domain answering, off-domain refusal or medical-advice refusal. All 23 pass.
23 / 23 passing
Tests80 unit tests over the agent loop, the guardrails and the tools.
80 unit
CoverageTests exercise every branch of the shipped code. Coverage is held at 100% as a gate.
100% branch
GuardrailsIntent classification, a filter before the model call and a filter after it. They refuse medical advice and off-domain requests.

IsolationEach tool takes the patient from the server session. The client never supplies an ID, so no prompt can reach another patient's data.

002

LLM from scratch

Gujarati GPT-2

Problem
Build a small causal language model for Gujarati from random initialisation, with a tokenizer fitted to the language.
Built
6 layers, 512 hidden, 64,000-token SentencePiece vocabulary, 256-token context. Trained 5 epochs in FP16 with AdamW on Gujarati news headlines.
Result
About 52M parameters, open on Hugging Face. Known limit: trained on headlines, so long text can drift.

Gujarati LLaMA2 Base

Try a LLaMA2-style architecture sized for a low-resource corpus.
Built
6 layers, 512 hidden, 16 heads, 64,000 vocabulary, 1,024 context, about 97M parameters, on roughly 2 GB of Gujarati text. Custom learning-rate schedule with gradient-norm tracking.
Result
Base model released on Hugging Face.
